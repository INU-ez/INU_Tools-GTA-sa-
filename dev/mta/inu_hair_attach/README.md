# INU Hair Attach — ассеты персонажей в MTA:SA

Ресурс надевает причёски/шапки/очки на педов и игроков **без правки их DFF**:
ассет живёт отдельной моделью и каждый кадр цепляется к кости через
`attachElementToBone`.

Требуется **MTA 1.5.8 r20704+** (`attachElementToBone`, `onClientPedsProcessed`,
`engineRequestModel("object")`).

---

## Быстрый старт

1. Экспортировать причёску из INU Tools (см. ниже) → `models/afro_long.dff`
   и `models/afro_long.txd`.
2. Прописать пару в `meta.xml` (`<file src="..." />`) и запись в `hair_defs.lua`.
3. Запустить ресурс, в игре: `/hair afro_long`.
4. `/hairadj` — режим подгонки. Двигать цифровым блоком и стрелками, пока
   волосы не сядут на голову. `/hairsave` печатает готовую строку — вставить
   её в `hair_defs.lua` вместо `pos/rot/scale`.
5. `/hair` без аргумента — снять.

Из других ресурсов:

```lua
exports["inu_hair_attach"]:wearHair(thePlayer, "afro_long")
exports["inu_hair_attach"]:removeHair(thePlayer)
```

Работает на любом `ped`, не только на игроках. Синхронизация идёт через
element data `inu:hair`, так что причёску видят все.

## Кости

`bone` в `hair_defs.lua` — ID кости MTA:

| ID | Кость | ID | Кость |
|----|-------|----|-------|
| 3  | SPINE1 | 25 | R.HAND |
| 4  | UPPERTORSO | 26 | R.THUMB |
| 5  | NECK | 32 | L.SHOULDER |

| 22 | R.SHOULDER | 41/51 | L/R.HIP |

## Экспорт ассета из INU Tools

Ассет для рантайм-привязки — это **обычный объектный DFF**, а не скин.
Никакой арматуры, никаких вертекс-групп костей: скелет ему не нужен, за
позицию отвечает `attachElementToBone`.

### 1. Origin — самое важное

Объект цепляется к кости **своим origin**. Чтобы `pos`/`rot` в конфиге были
близки к нулю (и подгонка заняла минуту, а не час):

1. Импортировать нужного педа: **INU Tools → Персонажи → Импорт DFF**.
2. Смоделировать/подогнать волосы прямо на его голове.
3. Встать в Pose Mode на арматуре педа, выделить кость `Head`,
   **Shift+S → Cursor to Selected** (3D-курсор встаёт ровно в кость головы).
4. Выделить меш волос, **Object → Set Origin → Origin to 3D Cursor**.
5. Убрать педа из выделения — дальше экспортируется только меш волос.

Не забыть **Ctrl+A → Rotation & Scale** на меше волос: несапплайные
трансформы уедут в игре.

### 2. Материал и текстура

* Одна текстура, один материал — это носится на каждом педе в кадре.
* Имя текстуры в материале = имя записи в TXD (INU Tools подставляет его сам
  при экспорте; если меняли картинку — проверьте `inu.texture_name`).
* Альфа (пряди-плоскости): включить альфу в материале, метод отрисовки —
  **Колебание / DITHERED** (стандарт GTA). TXD-экспорт сам возьмёт DXT3/DXT5.
* Полигонов держать мало: ориентир **до ~1500–2000 треугольников**.

### 3. Prelight (иначе чёрное в игре)

Объектные модели SA светятся по prelight-вертекс-цвету. Если экспортировать
меш без него, в игре причёска будет тёмной/чёрной.
**INU Tools → Prelight → применить пресет** (нейтральный/белый) перед экспортом.

### 4. Сам экспорт

* **DFF:** выделить только меш волос →
  `File → Export → INU Export DFF — single model (vehicle / ped)`.
  Игру в шапке диалога поставить **GTA SA**. Так как арматуры нет, экспортёр
  запишет обычный статический DFF с одним атомиком — то, что нужно.
* **TXD:** `File → Export → INU Export (.dff/.col/.txd/.ide/.ipl)` либо
  отдельный TXD-экспорт с галкой **«Только выделенное»**. Имя файла — то же,
  что у DFF.
* **COL не нужен:** у привязанного объекта коллизии выключены
  (`setElementCollisionsEnabled(obj, false)`), а `engineRequestModel("object", 1337)`
  наследует коллизию модели-донора.

### 5. Положить в ресурс

```
inu_hair_attach/
  models/
    afro_long.dff
    afro_long.txd
```

`meta.xml`:

```xml
<file src="models/afro_long.dff" />
<file src="models/afro_long.txd" />
```

`hair_defs.lua`:

```lua
["afro_long"] = {
    label = "Афро (длинное)",
    dff   = "models/afro_long.dff",
    txd   = "models/afro_long.txd",
    bone  = 8,
    pos   = { 0.0, 0.0, 0.0 },
    rot   = { 0.0, 0.0, 0.0 },
    scale = 1.0,
    lod   = 170,
},
```

## Ограничения этого подхода

* Волосы — **жёсткий объект на одной кости**. Они не деформируются вместе с
  телом: длинные пряди на плечах будут протыкать торс в анимациях. Для таких
  причёсок правильнее скинить меш и влить его в DFF педа (тогда это уже не
  рантайм-attach, а правка модели).
* Работает **только в MTA**. В синглплеере (и в SA-MP) нужен свой механизм:
  либо влитая в DFF геометрия, либо CLEO / `SetPlayerAttachedObject`.
* `engineRequestModel` выдаёт разные ID на разных клиентах и после рестарта
  ресурса — на ID нельзя завязываться, только на ключ из `HAIR`.
* Освобождение ID в `onClientResourceStop` обязательно, оно уже есть в
  `client.lua`.
